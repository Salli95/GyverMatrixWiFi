Подсказка по доступу
  • Если плата в домашней сети, в большинстве случаев работает адрес: http://matrix.local
  • При первом включении плата создает сеть MatrixAP (192.168.4.1).
  • Для гарантированной работы с Vercel по HTTPS в браузере разрешите запросы к локальной сети (Private Network Access) или используйте адрес платы напрямую.
