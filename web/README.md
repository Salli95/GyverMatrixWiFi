# GyverMatrix Cloud Web Control (Vercel)

Веб-приложение для управления адресной матрицей GyverMatrix (WS2812B 16x16 на ESP8266) с любого браузера и мобильного устройства.

## Возможности
- **Автопоиск матрицы (IP Scanner)**: автоматическое сканирование локальной Wi-Fi сети для поиска платы без необходимости знать ее IP или настраивать статический адрес на роутере.
- **Поддержка mDNS**: по умолчанию подключается к `http://matrix.local`.
- **40+ эффектов**:
  - 🎃 **Хэллоуин**: *Тыква Джек, Привидения, Глаза во тьме, Паук и паутина, Котел ведьмы, Капли крови*.
  - 🎄 **Новый Год**: *Ёлочка со звездой и гирляндой, Праздничная гирлянда, Салют / Фейерверк, Метель, Северное сияние, Снегопад*.
  - 🔥 **Классика**: *Огонь, The Matrix, Радуга, Звездопад, Шарики, Конфетти*.
  - 🌊 **Шумы**: *Цветной шум, Облака, Лава, Плазма, Лес, Океан*.
- **Бегущая строка**: отправка любого текста с палитрой цветов.
- **Студия рисования 16x16**: интерактивный холст для рисования в реальном времени с поддержкой сенсорных экранов.
- **Виртуальный геймпад**: сенсорный джойстик для аркадных игр (Змейка, Тетрис, Runner, Flappy, Арканоид, Лабиринт).

## Как задеплоить на Vercel за 1 минуту

### Вариант 1: Через консоль Vercel CLI
1. Откройте терминал в папке `web/`:
   ```bash
   cd web
   npx vercel
   ```
2. Следуйте подсказкам в терминале (выберите аккаунт и проект).
3. Сайт мгновенно появится в сети (например: `https://gyver-matrix-control.vercel.app`)!

### Вариант 2: Через интерфейс vercel.com
1. Зайдите на [vercel.com](https://vercel.com) и войдите в свой аккаунт.
2. Нажмите **Add New...** -> **Project**.
3. Подключите ваш GitHub-репозиторий и укажите Root Directory: `web`.
4. Нажмите **Deploy**.

## Важное примечание по сетевой безопасности браузеров (Private Network Access)

Когда веб-сайт открывается по защищенному протоколу HTTPS (`https://...vercel.app`), современные браузеры (Chrome, Safari) могут требовать разрешения на обращение к локальной сети (`http://192.168.x.x` или `http://matrix.local`):
1. **В Google Chrome**: при первом поиске нажмите «Разрешить» во всплывающем уведомлении о доступе к устройствам в локальной сети.
2. **Прямой локальный доступ**: Вы также можете открыть веб-интерфейс напрямую с самой платы, просто перейдя по адресу:
   ```
   http://matrix.local
   ```
   или по локальному IP-адресу платы (который матрица показывает бегущей строкой при старте).
